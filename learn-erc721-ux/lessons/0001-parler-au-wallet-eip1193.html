TD ERC721 UX 101 · Leçon 0001 · ~15 min

Parler au wallet : le provider EIP-1193

Ce que fait vraiment window.ethereum, sans librairie.

Objectif : à la fin, tu pilotes MetaMask à la main depuis la console du navigateur, et tu sais expliquer chaque ligne de erc721-ux/src/hooks/useWallet.ts au prof. Ça couvre les points 1 et 3 de « Wallet Integration ».

1. Un objet, une seule fonction

MetaMask injecte dans chaque page un objet appelé provider. Par convention il s'appelle window.ethereum, mais la spec précise que ce nom n'en fait pas partie[1193]. On lui parle avec une seule fonction :

const result = await window.ethereum.request({ method: "…", params: [ … ] });

La promesse est résolue avec le résultat de la méthode, ou rejetée avec une erreur qui porte un code numérique[1193]. Pour te connecter, changer de réseau ou signer, tu changes seulement la chaîne method.

Sepolia a le chain ID 11155111, soit 0xaa36a7 en hexadécimal. Le wallet parle toujours en hexadécimal[3326]. C'est pour ça que useWallet.ts appelle toHex(chain.id).

3. Deux événements à écouter

Le provider fonctionne comme un EventEmitter Node : il a on et removeListener[1193].

ethereum.on("accountsChanged", (accounts) => …); // string[] (vide = déconnecté)
ethereum.on("chainChanged",    (chainId)  => …); // string hexadécimale

Sans ces événements, ton state React garde l'ancien compte quand l'utilisateur en change dans MetaMask. Ton app enverrait alors des transactions en croyant parler à une autre adresse.

5. À toi : pilote MetaMask depuis la console

Ouvre http://localhost:3000 (npm run dev dans erc721-ux/), puis la console DevTools (⌥⌘J). Tape chaque ligne et note ce que tu observes avant de passer à la suivante.

  1. await ethereum.request({ method: "eth_chainId" })
    Quel réseau ? Compare avec le tableau ci-dessus.
  2. ethereum.on("chainChanged", id => console.log("chaîne :", id))
    Change ensuite de réseau dans MetaMask. Le log apparaît-il ? Sous quelle forme ?
  3. await ethereum.request({ method: "wallet_switchEthereumChain", params: [{ chainId: "0xaa36a7" }] })
    Selon le wallet, une popup s'ouvre (MetaMask) ou le changement est immédiat (Rabby). EIP-3326 dit seulement que le wallet should demander confirmation[3326]. Si une popup apparaît, clique Refuser et lis le code de l'erreur. Sinon, regarde ce que renvoie la promesse.
  4. await ethereum.request({ method: "eth_accounts" }), puis change de compte dans MetaMask et relance la ligne.

Attendu : "0x…" en hexadécimal, un log à chaque changement de réseau, null quand le switch a réussi (ou le code 4001 si tu as refusé une popup), et une liste qui change avec le compte. Si tu vois autre chose, demande-moi pourquoi : c'est souvent là qu'on apprend le plus.

6. Rappel, de mémoire

Ferme la leçon (ou fais défiler pour masquer la section 2) et réponds sans regarder.

Que renvoie eth_requestAccounts quand l'utilisateur accepte ?
Un string[]. C'est pour ça que le code prend accounts[0]. Le wallet ne donne jamais la clé privée : c'est tout l'intérêt du provider.
Sous quelle forme passer le réseau à wallet_switchEthereumChain ?
EIP-3326 : chainId « MUST specify the integer ID of the chain as a hexadecimal string ». Un nombre est rejeté.
Le wallet rejette avec code: 4001. Que s'est-il passé ?
4001 = User Rejected Request (EIP-1193). Les autres réponses correspondent à 4902, 4900 et 4200.
Quand faut-il appeler wallet_addEthereumChain ?
Seulement quand le réseau est inconnu (4902). Si tu l'appelles sur n'importe quel échec, un refus de l'utilisateur ouvre une seconde popup.
Au chargement de la page, pourquoi useWallet.ts appelle eth_accounts et pas eth_requestAccounts ?
eth_accounts ne déclenche jamais de popup : il récupère une connexion déjà autorisée, ou []. On garde eth_requestAccounts pour le clic sur « Connect ».
Écris le nom exact de l'événement à écouter pour savoir que l'utilisateur a changé de compte.
accountsChanged. Il reçoit un string[], vide si l'utilisateur a déconnecté le site.
Écris le chain ID de Sepolia tel que le wallet l'attend.
0xaa36a7, soit 11155111 en hexadécimal. Vérifie-le dans la console : (11155111).toString(16).
