Provider EIP-1193 : aide-mémoire

window.ethereum, WalletConnect et tout provider conforme exposent la même interface.

Appel

await provider.request({ method, params })   // résout le résultat, ou rejette { code, message }

Méthodes

methodparamsrenvoie
eth_requestAccounts—string[] (popup)
eth_accounts—string[], [] si non autorisé (sans popup)
eth_chainId—"0x…"
wallet_switchEthereumChain[{ chainId: "0xaa36a7" }]null
wallet_addEthereumChain[{ chainId, chainName, nativeCurrency, rpcUrls, blockExplorerUrls }]null

Événements

provider.on("accountsChanged", (accounts: string[]) => …)   // [] = déconnecté
provider.on("chainChanged",    (chainId: string)    => …)   // hexadécimal
provider.removeListener(event, handler)                     // dans le cleanup du useEffect

Erreurs

codesenssource
4001refus de l'utilisateurEIP-1193
4100non autorisé (compte ou méthode)EIP-1193
4200méthode non supportéeEIP-1193
4900 / 4901déconnecté de toutes les chaînes / de celle demandéeEIP-1193
4902réseau inconnu → wallet_addEthereumChainMetaMask
-32002requête déjà en attente dans la popupMetaMask

WalletConnect (même interface)

const wc = await EthereumProvider.init({ projectId, optionalChains: [11155111], rpcMap, showQrModal: false, metadata });
wc.on("display_uri", (uri) => /* dessiner le QR */);
await wc.connect();               // attend l'acceptation sur le téléphone
wc.on("disconnect", …);           // déconnexion depuis le téléphone

Sepolia

Chain ID 11155111 = 0xaa36a7. Pour convertir dans la console : (11155111).toString(16).

Switch avec fallback

try {
  await provider.request({ method: "wallet_switchEthereumChain", params: [{ chainId: "0xaa36a7" }] });
} catch (e) {
  if (e.code !== 4902) throw e;          // 4001 etc. : ne pas ajouter
  await provider.request({ method: "wallet_addEthereumChain", params: [{ … }] });
}
