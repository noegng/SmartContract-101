viem : lire et écrire un contrat

publicClient = RPC (lectures). walletClient = wallet (signatures).

Lire (view / pure)

const value = await publicClient.readContract({ address, abi, functionName: "totalSupply", args: [] });

Pas de gas, pas de fenêtre de wallet. uint256 → bigint (42n), à afficher avec .toString().

Écrire (3 étapes)

const { request } = await publicClient.simulateContract({ account, address, abi, functionName, args });
const hash = await walletClient.writeContract(request);         // fenêtre du wallet
const receipt = await publicClient.waitForTransactionReceipt({ hash });
if (receipt.status !== "success") throw new Error("reverted");

Payable

simulateContract({ …, value: parseEther("0.01") })              // ETH envoyé avec l'appel

Lire la raison d'un revert

if (e instanceof BaseError) {
  const r = e.walk((x) => x instanceof ContractFunctionRevertedError);
  if (r instanceof ContractFunctionRevertedError) r.reason;     // "Evaluator: no FakeBAYC held"
}

Le typage vient de l'ABI

L'ABI en as const permet à viem d'inférer functionName, args et le type de retour. Une erreur TS sur ces champs veut presque toujours dire : ABI incomplète ou fausse.
